KYNFINITY CONSULTING - GITHUB PAGES
===================================

This package is configured for the repository:
https://github.com/freedomskillhub-cell/kynfinity

Upload/commit ALL contents of this folder to the repository root. Do not
upload only index.html. The assets, media, and services folders are required.

Then open Settings -> Pages -> Deploy from branch -> main -> /(root).
The expected URL is: https://freedomskillhub-cell.github.io/kynfinity/
